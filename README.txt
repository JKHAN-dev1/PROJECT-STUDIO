STUDENT RECORD MANAGEMENT SYSTEM
CSD0111 – PROJECT STUDIO-I

HOW TO RUN
1. Extract this ZIP file.
2. Open the Student_Record_Management_System folder.
3. Double-click index.html. It opens in a modern browser.
4. Add a student using the form.
5. Use Search, Edit, Delete and Export CSV to test the features.

FEATURES
- Add, view, search, update and delete student records
- Unique Student ID validation
- Marks validation (0 to 100)
- Automatic average and grade calculation
- Dashboard: total students, class average and top performer
- CSV export for opening records in MS Excel
- LocalStorage saves records in the same browser profile

GRADE SCALE USED
A+ : 90–100
A  : 80–89.99
B  : 70–79.99
C  : 60–69.99
D  : 50–59.99
F  : Below 50

IMPORTANT
This is a front-end educational demonstration. Records are stored only in the
current browser profile on this device. It does not use a server or shared database.
